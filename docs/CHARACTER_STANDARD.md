# 角色标准

主角身高暂定 1.8m，人体比例待三视图审批。正侧背视图须共用比例线。脚底中心为原点，正面 -Z，应用缩放后导出 GLB。绑定姿势暂用 A-pose，骨骼以 root/pelvis/spine/chest/neck/head 及左右 limbs 命名并固定，正式命名待模型审批。

身体、衣物、金属、发光分材质，主角贴图暂按 2K 规划，最终预算待确认。权重归一化，优先每顶点四骨骼。检查肩肘髋膝极限变形、足底接触与循环。正式模型挂在 Player/Visual/ModelSocket 下，动画接口输出 idle/walk/run 和真实水平速度，后续分身复用同一资源和动作语义。

视觉设计以 [主角视觉风格规范 V1.0](art/CHARACTER_VISUAL_STYLE.md) 为依据。1.8m 仅用于当前占位控制测试，正式身高与头身比例待三视图确认。
