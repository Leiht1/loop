# 角色标准

主角身高约 1.78m，约 7.5 头身，以本轮确认的东方幻想青年游侠三视图为依据。正侧背视图须共用比例线。脚底中心为原点，Godot 正面为 -Z，按米制导出 GLB。绑定使用自然 A-pose，骨骼以 root/pelvis/spine/chest/neck/head 及左右肢体命名。

身体、衣物、金属、发光分材质，主角贴图暂按 2K 规划，最终预算待确认。权重归一化，优先每顶点四骨骼。检查肩肘髋膝极限变形、足底接触与循环。正式模型挂在 Player/Visual/ModelSocket 下，动画接口输出 idle/walk/run 和真实水平速度，后续分身复用同一资源和动作语义。

视觉设计以 [主角视觉风格规范 V1.0](art/CHARACTER_VISUAL_STYLE.md) 和本轮确认的参考图为依据。现有玩家胶囊高度为 1.8m。
