# 第一阶段测试报告

2026-11-12。新增文件包括 docs 下 12 份规范、本报告与画面截图，Loopbound 下 project.godot、主场景、main.gd、三个职责独立的控制脚本、回归测试和运行说明，以及根 .gitignore。初始目录为空，无覆盖用户文件。

## 实际验证

Godot 4.7.2 编辑器 headless 导入成功。实际图形运行 120 帧正常退出，RTX 3060 / Vulkan / Forward+，未输出错误和警告。查看 phase_1_preview.png，地面、边界、占位角色、阴影和居中构图正常。

自动测试以真实物理帧运行，验证落地、前进、行走状态、跑速、奔跑状态、停下待机、相机相对移动、边界碰撞和 SpringArm 遇墙收缩。最终结果 FAILURES 0。无显示模式跳过鼠标捕获测试。俯仰断言仅验证范围，不代表完整鼠标操作验收。首次图形自动输入受焦点和真实鼠标影响失败，后改为无显示物理回归，未将该次失败当作通过。

## 待验收

鼠标捕获与 Esc 实际操作、连续转向手感、墙角镜头抖动、建筑碰撞全部路径及长时间性能尚未完成交互验收。正式角色和 idle/walk/run 骨骼动画尚未制作，目前只有状态与混合参数接口。Windows 导出模板与可执行文件导出未验证。因此当前交付为可启动开发基础，第一阶段完整验收仍有上述待办。
