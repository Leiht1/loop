# 《回环》主角视觉风格规范 V1.0

## 一、角色定位

- 角色身份：男性青年游侠。
- 所属世界：东方幻想世界。
- 角色气质：年轻、洒脱、灵动、沉稳中带有冒险精神。
- 视觉定位：具有鲜明辨识度的东方幻想动作游戏主角。
- 设计目标：既有独特的角色风格，又适合独立游戏的3D建模、动画制作和后续资产扩展。

## 二、整体美术风格

采用具有一定写实质感的风格化3D设计。

不采用纯写实风格，也不采用过度Q版或幼稚的卡通风格。

核心要求：
1. 东方幻想气质明确，但不局限于传统武侠。
2. 服装有设计感和层次，避免过于朴素。
3. 造型简洁利落，不能依靠大量装饰堆砌细节。
4. 角色轮廓清晰，远距离也具有辨识度。
5. 材质有质感，但不追求复杂的表面细节。
6. 整体视觉风格统一，不能像不同游戏素材拼接而成。

## 三、角色外观

### 1. 发型
- 深色头发，以黑色、深棕色为主要方向。
- 发型自然、有一定蓬松感。
- 可以采用部分束发设计。
- 保留少量发束变化，避免过度复杂的发型结构。
- 发型应适合3D骨骼和后续动作制作。

### 2. 服装
以当前确认的青年游侠参考图为基础。

主要特征：
- 东方风格的上衣与裤装。
- 上衣采用适度宽松的剪裁，袖口具有一定特色。
- 服装可以有内外层次，但不采用过多叠穿。
- 腰部使用简洁的束带或腰绳。
- 下装宽松但不能影响动作表现。
- 鞋靴具有东方风格，同时适合跑动、跳跃和战斗。
- 可以有一件具有辨识度的披肩、围巾或短披挂，但不堆叠多个飘动部件。

### 3. 标志性设计
允许少量具有记忆点的元素，例如：
- 特殊衣领或袖口。
- 少量东方纹样。
- 一处具有辨识度的腰部装饰。
- 少量红色系点缀。
- 具有特殊含义的饰物。

不要求全部使用，具体以整体视觉协调为准。

## 四、颜色规范

目前确定的参考配色：

- 主色：米白色。
- 辅助色：深青蓝、墨蓝。
- 点缀色：赭红、暗红。
- 其他材质：深棕、灰黑。

整体要求：
- 颜色克制，不使用过多高饱和颜色。
- 主色与辅助色形成明显区分。
- 点缀色只用于少数关键位置。
- 不要让角色整体变成单一灰黑色。
- 后续装备可以在此基础上适当变化，但保持整体协调。

## 五、材质规范

主要材质：
- 布料：服装主体。
- 皮革：少量束带、护腕等部位。
- 木材：后续武器与道具。
- 金属：少量兵器和装饰。
- 玉石：特殊道具或重要装备。

材质需要有适度的明暗变化和质感，但不需要大量复杂纹理。

## 六、3D制作约束

本规范不仅考虑最终画面，也必须考虑实际制作成本。

1. 避免过多独立的小型装饰模型。
2. 优先将纹样、缝线等细节融入贴图。
3. 服装尽量采用合理的整体模型结构。
4. 避免大量悬挂物、复杂绳结和长飘带。
5. 减少需要单独制作骨骼的装饰物。
6. 服装不能严重影响手臂、腿部和躯干的动作。
7. 模型需要适合第三人称摄像机观察。
8. 保证正面、背面和侧面都有完整、协调的造型。

## 七、明确禁止的设计方向

- 不采用大众化的西式冒险者服装。
- 不采用常见的皮革工装、户外探险服搭配。
- 不使用大量腰包、背包和挂件堆砌造型。
- 不设计满身密集纹样和金属装饰。
- 不采用过于朴素、缺乏辨识度的普通布衣。
- 不采用过度华丽、难以建模的复杂服装。
- 不为了视觉细节而牺牲动作表现。

## 八、与游戏整体美术的统一

《回环》确定采用东方幻想世界风格。

后续所有相关资产应遵循统一的视觉方向：

- 武器：东方幻想兵器设计。
- 技能：东方幻想视觉语言。
- 场景：东方幻想建筑、遗迹和自然环境。
- 道具：与世界观相符的东方风格器物。
- 敌人：根据世界观进行原创设计。

不要求所有东西都采用传统中国古代元素，可以融入原创幻想设计。

## 九、后续设计与制作规则

1. 当前确认的主角参考图作为视觉方向依据。
2. 不得擅自改变男性青年游侠的基本定位。
3. 新增服装和装备时，优先考虑与主角原有风格的协调性。
4. 后续正式建模前，需要先确认角色三视图。
5. 三视图确认后，再进行Blender建模、骨骼绑定和动画制作。
6. 未经确认，不得擅自增加大量服装细节或改变主要配色。

## 十、当前确定状态

已确定：
- 东方幻想世界风格。
- 男性青年游侠主角。
- 具有适度设计感的简约东方服装。
- 米白、深青蓝为主，赭红点缀。
- 适度细节，避免过度装饰。
- 优先考虑3D建模和动画制作成本。

尚未最终确定：
- 主角姓名与背景故事。
- 最终发型细节。
- 精确服装结构。
- 最终角色身高和头身比例。
- 标志性武器。
- 专属饰物及其世界观含义。

本规范是后续主角设计、3D建模及相关美术资产制作的统一依据。
