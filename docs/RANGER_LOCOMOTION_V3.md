# 当前主角常规动作

使用校正后的 71 骨角色。当前八段动作为 idle、walk、run、look_around、dodge_front、dodge_back、dodge_left、dodge_right。

## 游戏与预览

打开 `Loopbound/project.godot`，F5 运行游戏。WASD 或方向键移动，Shift 奔跑，空格闪避。单按空格沿角色前方，有方向输入时沿镜头相对方向。站立约 5 秒后播放环顾，移动和闪避会淡出环顾。

独立检查打开 `Loopbound/scenes/characters/player/locomotion_v3.tscn`，按 F6。1 待机、2 走路、3 奔跑、4 前闪、5 后闪、6 左闪、7 右闪、8 环顾。F1/F2/F3 切换正侧背，空格暂停，G/T 切换灰模和材质。

## 步态与重定向

走路、奔跑和环顾参考用户提供的 Tripo 动画。保留当前模型、校正后的原 41 骨静止矩阵以及新增 30 根手指骨。参考动画经过轴向转换、世界旋转差重定向与腿长适配，去除参考中的整段水平移动。脚步重新求解到当前腿长，约束脚间距、脚尖朝向与落地高度。环顾时双脚固定在当前站位，保留身体与头部转动。

走路 2m/s，参考动作以 1.65 倍节奏播放。奔跑 4m/s，以 0.94 倍节奏播放。奔跑手指保持握拳。奔跑参考的首尾偏差分摊到整段动作，保持末段步态连续，并重新校正落脚。

膝盖弯曲平面收窄到接近前后方向。腿部前后摆幅缩短到上一版的 76%，走路骨盆额外下沉由 4cm 减至 0.5cm。脚掌使用参考动作的稳定俯仰，脚趾保持中性姿态，避免抬脚时朝向翻转或鞋底额外扭曲。

## 四向闪避

前闪 3.3m、后闪 2.8m、左右各 3.0m，一段 0.8 秒。中段保持提膝悬空滑行，随后落地收势。保持提膝腿的膝盖姿态，踝关节随小腿方向调整，让脚掌自然下垂，避免脚面贴住小腿。蹬地阶段加入少量下沉以适应加长位移。

水平位移采用三次 Hermite 曲线，经过角色碰撞求解。行走切入闪避时延续进入速度并渐变衰减，补偿整段位移保证最终距离。走跑混合在闪避覆盖期间继续推进，淡入 0.09 秒、淡出 0.12 秒。游戏内使用独立动画副本移除水平 Root 轨道，预览保留烘焙位移。

## 制作文件与验证

可编辑源为 `assets_source/characters/ranger/locomotion_v3.blend`。模型为 `Loopbound/assets/characters/ranger/action_comparison/locomotion_v3.glb`，包含 12 个角色网格、71 个蒙皮关节和原有材质。

重建脚本为 `build_locomotion_v3.py`，依赖当前中性姿态与网格参考 `locomotion_motion_reference.blend`，以及 `animation_inputs/tripo_motion_reference.glb`。逐帧验证脚本为 `verify_locomotion.py`。通过 Blender 后台运行，添加 `--python-exit-code 1` 使失败返回非零状态。

验证覆盖静止骨架兼容、八动作支撑脚与关节连接、膝肘范围、首尾连续，以及闪避中段的悬空、姿态保持与踝关节角度。Godot 检查覆盖输入、步态播放、移动切入闪避、四向实际距离、碰撞、环顾触发和打断。详细接入见 `RANGER_ANIMATION_HANDOFF.md`。

当前已接入主关卡。衣摆、手指接触、起停转向和战斗取消窗口继续打磨。

本轮修正靴筒与腿轴的蒙皮后偏移，并对裤腿下部平滑过渡。按中性站姿的可见靴筒截面校正，不仅检查骨骼节点。奔跑重定时按倒序调整增大的关键帧时间，避免索引重排造成停顿。导出动画起点统一为零，消除循环前的空白帧。

本轮细调将放松手指弯曲提高至 0.28。奔跑骨盆向前移 7.5cm，保持摆臂和脚步轨迹，改善腰部落后于上身与前摆腿的姿态。抬腿时脚掌随小腿自然下垂，低位落脚时平滑回到参考俯仰。
