# 当前主角动画与游戏接入

Godot 打开 `Loopbound/project.godot`，F5 运行主关卡。当前角色为 71 骨，保留校正后的关节点和现有模型。用户提供的 `tripo_motion_reference.glb` 用作走路、奔跑和环顾的动作参考，经过轴向转换、旋转重定向、腿长适配和落脚约束烘焙到当前角色。

## 操作与移动

WASD 或方向键移动，Shift 奔跑，空格闪避。单按空格沿角色当前前方，有方向输入时沿镜头相对方向。斜向输入保留斜向位移，选取相对角色最接近的四向动作。

走路 2m/s、奔跑 4m/s。走路按参考节奏的 1.65 倍、奔跑按 0.94 倍播放，匹配重定向后步幅。脚间距约 19cm，膝盖使用略向外的弯曲平面，脚尖保持轻微外展。步态、摆臂、躯干重心与胸肩配合来自参考动画，保留当前手指绑定与奔跑握拳。

站立约 5 秒后播放一次环顾。环顾结束后重新计时，移动或闪避会淡出环顾。环顾仅使用参考的身体动作，角色双脚保持在当前位置。

## 闪避

前方 3.3m、后方 2.8m、左右各 3.0m，一段 0.8 秒。三次 Hermite 曲线匹配蹬地、保持屈膝滑行及落地收势。行走中切入时延续进入速度并平滑衰减，整段位移补偿保证总距离。走跑混合在闪避下继续推进，结束后按当前输入恢复移动。

保持提膝腿的屈膝姿态，修正踝关节，使脚掌随小腿自然下垂。加长距离后的蹬地增加轻微下沉吸收，防止支撑腿过伸。

实际移动通过 CharacterBody3D 碰撞求解。游戏使用独立动画副本去除水平 Root 位移，保留垂直提身。预览资源仍保留烘焙位移。
