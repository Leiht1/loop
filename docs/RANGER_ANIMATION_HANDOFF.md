# 主角动画对比交接

截至 2026-11-13，已保留两份 Tripo 导出的 GLB。两版的对比绑骨、权重和动画测试留到下一次会话。对比结果用于确定后续 3D 素材采用哪条生成路线。

| 素材 | 已确认状态 |
| --- | --- |
| [主角骨骼.glb](../assets_source/characters/ranger/animation_inputs/主角骨骼.glb) | T 姿势，Tripo 拆分预览为 96,284 个三角面。GLB 有 12 个网格和内嵌贴图。虽然文件名带「骨骼」，导出文件没有蒙皮或动画数据。 |
| [主角网格拓扑.glb](../assets_source/characters/ranger/animation_inputs/主角网格拓扑.glb) | 约 5,000 面档的四边面路线，界面预览显示 6,062 面，接近 A 姿势。GLB 有一个网格，无贴图、蒙皮或动画。GLB 导入后按三角形渲染，检查四边面布线时以原拓扑视图为准。 |

两个文件是对比输入。工程主场景当前引用另一个 `ranger_tripo.glb`，该文件有贴图但没有动画。工程里也已有带 `idle`、`walk`、`run` 的早期 `ranger.glb`，可作为动作来源候选，复用前检查骨骼映射。两份对比输入尚未接入主场景。

## 下次开始时

1. 在独立测试场景或工作副本中分别导入两版。先检查比例、朝向、脚底原点和分件接缝。统一身高、骨架命名和骨骼对应，处理 A、T 初始姿势的差异，再分别绑定并记录自动权重需要手工修正的位置。
2. 用同一套原地待机、行走和奔跑测试。追加抬臂过头、屈肘和深蹲，观察肩袖、肘膝、靴口和衣摆是否塌陷、开缝或穿插。两版先用灰模和相同镜头对比变形，再单独查看三角面版的贴图表现。
3. 分别记录绑骨及权重修正耗时、接缝处理、动作复用、脚底滑动和正常镜头下的观感。结合实际修正工作量和游戏内效果决定后续素材路线。先用现有文件完成对比，再决定是否有必要在 Tripo 付费重新生成。
