# 开发规则

按任务读取规范，修改前检查工作区，保护用户改动。不删除用途不明文件，不覆盖 Blender 源文件。检查仅为前置步骤，必须继续完成授权开发。运行 Godot 验证，未测试部分明确记录。阶段结束建立可恢复快照。未经授权不提交、推送或部署。只做最小必要改动，禁止提前加入管理器和范围外系统。

## 推送规则

- 仅提交与《回环》直接相关的工程文件、运行所需的模型与贴图、后续制作所需的源素材、测试、当前规范和交接文档。区分工程使用的贴图与仅供查看的渲染预览。
- 废弃报告、截图和预览图、临时实验输出、缓存、导出包和本地阶段快照留在本机。新出现的此类产物按实际路径加入忽略规则。
- 逐项暂存，提交前检查暂存文件清单和差异。推送前确认分支与远端；发现同一文件中有无关改动时，按改动范围暂存。

## 本地产物清理

每次开发收尾、生成新快照后和提交前，运行 `python tools/cleanup_local_artifacts.py`。预览文件按修改时间保留 7 天，快照最多保留最新 2 份且不超过 14 天，配套校验文件随快照清理。预演使用 `--dry-run`。清理仅限项目内 local_previews 与 snapshots。

提交前确认 `git ls-files -- local_previews snapshots` 无输出，暂存列表不得包含这两个目录。历史已跟踪文件应移出 Git 跟踪。正式源素材、工程文件及当前有效文档不进入临时产物目录。
