# LOOPBOUND

Godot 4.7.2 打开 `project.godot`，按 F5 运行游戏。

WASD 或方向键按视角前后移动及左右横移，鼠标控制朝向。Shift 前进奔跑，横移和后退加快至 1.5 倍速度与动作频率。空格四方向闪避，左键或 J 三连击，滚轮缩放，Esc 释放或恢复鼠标。

当前主角采用 71 骨角色与 Quaternius 站立、走跑、横移、后退和左右180°转身。原地0.5秒内累计转向达到180°时播放对应转身，小角度转动维持站立动作。转向输入短暂停止0.12秒后跟随朝向，持续慢转超过0.5秒及移动时实时跟随。转身期间由原版动画完成旋转，移动、攻击和闪避可打断。四方向闪避沿用原自制版本，距离为前方3.3m、后方2.8m、左右3.0m。站立右臂与握剑已作持剑适配。

用户下载的完整 Standard 原始素材位于仓库根目录 `素材/`，包含作者许可文件。

单独查看动作可打开 `scenes/characters/player/locomotion_v3.tscn`，按 F6。项目规范见 `../docs/README.md`。
